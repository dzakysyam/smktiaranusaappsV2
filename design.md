SENTRA SEDANG DIBANGUN sebagai aplikasi TU mandiri. Nama UI SENTRA, subjudul tepat “Tata Usaha SMK Tiara Nusa One”. Halaman minimal: daftar surat keluar, detail, form draf, status, riwayat, laporan TU. Gunakan bahasa Indonesia, label status tertulis, ringkasan sumber data jelas, feedback kesalahan terbacakan, keyboard focus terlihat, label input terhubung, viewport desktop dan mobile tanpa overflow. Token kerja sementara navy #123568, cream #F8F3E8, surface #FFFDF8, border #E5DFD4, text #2B3446; belum baseline resmi TU, bisa disesuaikan setelah review sekolah.

Portal Humanis punya sistem desain tersendiri di repo lain. Integrasi navigasi balik dan deep link masih rencana. Screenshot dan aksesibilitas harus diuji pada aplikasi yang benar-benar hidup, jangan memakai contoh layar Stitch sebagai bukti implementasi.
